### Miro

Miro is a collaborative whiteboard for brainstorming, sketching ideas, creating user flows, wireframes, and moodboards.
It is especially useful during the early stages of UI planning and visual exploration.

https://miro.com

### Adobe Color

Adobe Color is a tool for exploring ready-made color palettes and creating color combinations for UI projects.
Example: open the Explore section, search for terms like dark, finance, food, or technology, and use the HEX colors from a palette in your project.

https://color.adobe.com/


### Adobe Contrast Checker

Adobe Contrast Checker helps verify whether text and background colors have enough contrast for accessibility.
Enter the foreground and background colors to check if the combination meets WCAG contrast requirements.

https://color.adobe.com/br/create/color-contrast-analyzer

### Dribbble

Dribbble is a platform for finding UI/UX inspiration, including websites, mobile apps, dashboards, components, and visual concepts.
Search by keywords related to what you are building, such as mobile banking, dashboard, checkout, or login.

https://dribbble.com/

### Mobbin

Mobbin is a reference library focused on real-world mobile and web interfaces from popular products.
Use it to research how existing apps solve specific screens and flows, such as onboarding, login, checkout, navigation, and payments.

https://mobbin.com/


### Google Fonts

Google Fonts is a free library of fonts that can be used in websites, mobile apps, and other UI projects.
Use the filters to explore font styles, preview different texts, and choose typography that matches your interface.

Legibility: Prefer clear fonts that work well at different sizes and screens.

Personality: Use fonts like Roboto, Lato, Open Sans, Montserrat, or Poppins according to the tone of the interface.

Emotion: Serif fonts like Times New Roman feel more classic, while fonts like Lobster feel more informal.
Combinations: Use typography to create hierarchy and keep the UI to 2–3 font families.


https://fonts.google.com/
